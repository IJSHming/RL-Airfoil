# HPC 夜间无人值守深度自主科研模式 (Overnight Autonomous Workflow)

本技能专为用户在夜间休息或离线无人值守场景定制，旨在完全不需人类干预的情况下，最大化发挥智能体的主观能动性与系统工程能力。

## 1. 核心原则与心智模型
1. **时间充裕，从容实验**：你拥有整整 5 小时的时间预算（基于 HPC 6 小时限额保留 1 小时安全余量）。绝对不要着急，完全不需要刚得到一个勉勉强强的结果就火急火燎地提交，要从容实验出最好的版本；
2. **充分自省与假死防范**：无人值守期间没有人类实时提示，你必须主动承担长程任务的自省责任，杜绝任何无意义的进程卡死；
3. **追求真正卓越的科研成果**：开展多轮“假说-实验-诊断-改进”闭环，直到探索出兼具高升阻比、100% 物理可行性与良好泛化性能的成果。

---

## 2. 标准执行工作流

### 步骤 1：时间预算管理与后台计时
1. 记录任务启动时间戳，计算 5 小时截止时间点（18,000 秒）；
2. 可利用后台计时守护脚本（如 `hpc_timer.py`）或 `schedule` 工具，每隔 1 小时自检一次阶段性进展与时间余量。

### 步骤 2：满载并发启动与进程健康校验
1. 恪守 `GEMINI.md` 工作区规范：
   - **10 核 CPU** 满载进行多任务并行求解（NeuralFoil/AeroSandbox）；
   - **L40S GPU (48GB)** 负责批处理张量加速（GP 拟合、无似然代理模型训练或 LLM 推理），且保证无锁安全。
2. 任务启动后约 30~60 秒，主动执行资源检查：
   ```bash
   top -b -n 1 -u c250089 | head -n 25
   ```
   确认十个工作进程均有真实的 CPU/GPU 负载。若出现 0% 假死，立即中断诊断并修复。

### 步骤 3：多轮深度探索与充分验证 (Deep Iteration Loop)
1. **建立严谨基线**：记录初始客观基准，确保对比对照组公平可信；
2. **机理分析与针对性优化**：深入分析收敛曲线与动力学瓶颈，提出改进方案并实施；
3. **10 种子全面复核**：任何改动必须通过 10 个独立测试种子（42 ~ 9999）的全样本评估，杜绝单一随机种子的虚假繁荣；
4. **精益求精，从容重试**：若某轮策略收益不显著，不要气馁或草草交卷，从容分析原因，尝试其他学术架构或参数方案。

### 步骤 4：收尾整合、可视化与安全入库 (Graceful Finalization)
在距离 5 小时截止前约 30 分钟：
1. 停止启动新的长程计算，锁定历史测试中最优的算法逻辑与神经网络/代理模型权重；
2. 运行基准脚本持久化最终数据（`benchmark_results.json` 与 `.npz`）；
3. 运行绘图脚本生成出版级全套高清图表（300 DPI PNG 与 PDF 矢量图）；
4. 同步更新 `README.md` 与实验报告，提炼学术见解与物理机理；
5. 运行 `git add`、创建清晰的规范提交信息，并执行 `git push origin main` 推送至远程仓库。
