# RL-Meta-Airfoil: 强化学习与大模型元优化黑盒翼型气动外形设计

本项目面向 2D 跨音速/高亚音速巡航翼型气动外形优化基准（$Re=3.5 \times 10^6, \alpha=3.5^\circ$，18 维 **Kulfan CST** 连续参数化，初始基准 **NACA 0012**，初始 $L/D = 65.80$，严格评估预算 **NFE = 300**），在全套 10 项航空工业级几何与气动强约束下（最大相对厚度 `[8%, 20%]`、结构梁站位最小厚度、后缘防鱼尾单调收缩、前缘钝度半径、后缘闭合楔角、截面面积、抗波纹凸性、俯仰力矩 $C_M \ge -0.25$），系统对比评测三大元优化范式：
1. **纯净 RL-Meta（PPO 动态超参数元控制）**：覆盖 6 种经典黑盒优化器（SPSA、Py-BOBYQA、DE、PSO、CMA-ES、TuRBO），在严格排除测试工况的 $10 \times 11 = 110$ 气动网格工况上离线训练（220 回合，跨工况无标度相对增益奖励），全部 6 个优化器均满足**零动作恒等性**（`action = 0` 时与 Vanilla 基准比特级一致 `diff = 0.00e+00`，零隐藏启发式特权）；
2. **零泄漏停滞自适应 LLM-Meta-TuRBO**：直连本地 SGLang 推理 `Qwen/Qwen3.8-27B-FP8`，采用无数值答案提示词、对称正交宏观气动模式与 `post_init`（第 16 步）+ 真实停滞自适应触发（`stag_threshold = 10`）；
3. **严格原论文版 MALIBO（Pan et al., ICML 2024）**：直接调用 `Meta-CFD/malibo` 严格忠实于原论文 `MALIBO.pdf` 的无似然元贝叶斯优化实现（250 离线任务 / 75,000 样本，严格排除 $Re=3.5\times 10^6, \alpha=3.5^\circ$，无信赖域、无免费几何预筛器、全局 5,120 点随机采集搜索）。

## 1. 六大优化器纯净 RL-Meta 基准对比 (10 个独立随机种子, NFE = 300)

测试工况：$Re = 3.5 \times 10^6, \alpha = 3.5^\circ$，10 个独立随机种子（`42, 123, 256, 777, 1024, 2024, 3407, 5555, 8888, 9999`），所有优化器均已通过零动作恒等检验（`RL-Meta(action=0) == Vanilla`）：

| 优化算法 | 权威基准设定 | Vanilla ($L/D$) | 纯净 RL-Meta ($L/D$) | 绝对增益 ($\Delta$) | 相对增益 | 胜率 | 配对 $t$ 检验 ($p$) | 10 种子可行率 |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **SPSA** | Spall (1998) 跨度自适应摄动 | $186.93 \pm 21.08$ | $177.22 \pm 24.18$ | $-9.72$ | $-5.2\%$ | $4/10$ | $t=-0.827\ (p=0.429)$ | **100% (10/10)** |
| **Py-BOBYQA** | Powell (2009) 默认信赖域 ($\rho_{\text{beg}}=0.10$) | $136.19 \pm 30.95$ | **$160.67 \pm 23.13$** | **$+24.48$** | **$+18.0\%$** | $7/10$ | $t=+2.006\ (p=0.076)$ | **100% (10/10)** |
| **DE** | Storn-Price (1997) 边界散布 ($F=0.7, CR=0.8$) | $181.90 \pm 13.87$ | **$185.57 \pm 16.43$** | **$+3.66$** | **$+2.0\%$** | $6/10$ | $t=+0.522\ (p=0.614)$ | **100% (10/10)** |
| **PSO** | Clerc-Kennedy (2002) 压缩因子 ($\chi=0.7298$) | $195.24 \pm 13.52$ | $191.22 \pm 26.00$ | $-4.02$ | $-2.1\%$ | $4/10$ | $t=-0.571\ (p=0.582)$ | **100% (10/10)** |
| **CMA-ES** | Hansen (2006) 默认步长 ($\sigma_0=0.05$) | $189.19 \pm 11.69$ | **$209.03 \pm 11.09$** | **$+19.84$** | **$+10.5\%$** | **$10/10$** | **$t=+4.776\ (p=0.0010)$** | **100% (10/10)** |
| **TuRBO** | Eriksson et al. (2019) 信赖域 ($L_0=0.8$) | $195.73 \pm 12.32$ | **$206.81 \pm 14.21$** | **$+11.09$** | **$+5.7\%$** | $7/10$ | $t=+2.077\ (p=0.068)$ | **100% (10/10)** |

### 核心科研结论（零隐藏启发式纯净 RL-Meta）
1. **低维步长/信赖域尺度控制类优化器获益最显著**：在完全去除硬编码启发式后，纯 PPO 在 **CMA-ES** 上斩获 **$209.03 \pm 11.09$（$+19.84 / +10.5\%$，10/10 种子全胜，$p=0.0010$，Cohen's $d=+1.51$，且方差低于 Vanilla）**；在 **Py-BOBYQA** 上实现 **$+24.48$（$+18.0\%$，$d=+0.63$）** 的最大相对提升；在 **TuRBO** 上达到 **$206.81 \pm 14.21$（$+11.09 / +5.7\%$，$7/10$ 胜，峰值 $234.45$，$d=+0.66$）**；在 **DE** 上取得温和正向提升（$+3.66 / +2.0\%$）。
2. **客观揭示纯 RL 元控制在噪声与稳定性敏感算法上的真实边界**：在两点随机梯度高方差的 **SPSA**（$-5.2\%$）以及受 Clerc-Kennedy 特征值压缩稳定性严格约束的 **PSO**（$-2.1\%$，3 维无约束动作使 2 个种子出现发散振荡）上，纯黑盒 PPO 策略未能超越经过数十年理论标定的经典解析法则。这一诚实对比清晰界定了通用 RL-L2O 的适用边界，为引入语义先验（LLM-Meta）与离线轨迹元学习（MALIBO）提供了直接动机。
3. **100% 航空工程物理合规**：全场 120 组独立运行的最优设计可行率均为 **100%**。

## 2. 状态与动作空间设计 (零动作恒等性对齐)

各优化器共享 6 维通用状态特征（进度 $t/300$、归一化 $\log_{10} Re$、归一化 $\alpha$、累计相对收益、近期窗口收益、停滞比例）与跨工况无标度相对增益奖励，动作在 `action = 0` 时精确退化为对应 Vanilla 基线：

- **SPSA (10 维 State / 2 维 Action)**：增加步长/摄动比、梯度范数与连续梯度余弦夹角；动作独立调节 `scale_a` 与 `scale_c`。
- **Py-BOBYQA (10 维 State / 1 维 Action)**：增加信赖域半径 $\Delta$、收敛半径 $\rho$、模型梯度范数；动作调节信赖域缩放乘子 $\kappa_\Delta$（$\Delta \in [\rho, \max(4\rho_{\text{beg}}, \Delta)]$）。
- **DE (11 维 State / 2 维 Action)**：增加 $CR$、$F$、停滞、种群适应度方差与多样性；动作独立调节缩放因子 $F$ 与交叉率 $CR$。
- **PSO (11 维 State / 3 维 Action)**：增加 $w, c_1, c_2$、粒子分散度与速度范数；动作独立调节全部 3 维超参 $[w, c_1, c_2]$。
- **CMA-ES (9 维 State / 1 维 Action)**：增加 $\sigma$、进化路径比与协方差条件数；动作调节全局步长乘子 $\kappa_\sigma$。
- **TuRBO (10 维 State / 2 维 Action)**：增加局部信赖域长度 $L$、连续成功/失败计数、GP 后验不确定度；动作独立调节临时信赖域尺度 $\kappa_L$ 与汤普森探索温度 $\tau$。

## 3. 四大前沿范式综合对比：TuRBO vs RL-Meta vs LLM-Meta vs MALIBO

在完全统一的测试协议下（$Re = 3.5 \times 10^6, \alpha = 3.5^\circ$，NACA 0012 起步，共享比特级一致的 `n_init = 15` 初始设计，严格 `NFE = 300`，10 个独立随机种子）：
- **LLM-Meta-TuRBO（零提示词泄漏 + 停滞自适应）**：提示词仅提供通用翼型空气动力学与几何约束，不含任何数值偏移推荐；4 通道对称正交物理基（中弦弯度、后弦弯度、对称厚度、前缘半径）全部采用对称区间；仅在第 16 步触发一次 `post_init` 诊断，此后完全由真实停滞计数触发（`stag_threshold=10`，实测平均 **$5.10$ 次调用/种子**，范围 $3\sim 7$ 次）；临时信赖域乘子 12 步衰减，30% 方向候选严格裁剪于当前信赖域内。
- **MALIBO（严格对齐原论文 Pan et al., ICML 2024）**：4×64 ResFFN（ELU, $d=50$）、精确 Eq. (2) LFBO 损失 + 排序 KS/Cov 高斯先验正则（250 任务 / 75,000 样本，$z_t$ 收敛至 $\text{std}=0.9980$）、固定 $\gamma=1/3$ Laplace 汤普森采样、70/30 早停残差 GBDT 及全局 5,120 点均匀随机采集搜索（无信赖域、无免费几何预筛器）。

### 3.1 四大范式最终性能统计对比 (10 种子, NFE = 300)

| 优化算法范式 | 核心技术机制 | 升阻比均值 ($L/D$) | 中位数 | 极小 / 极大值 | 对比 TuRBO 增益 ($\Delta$) | 配对检验 vs TuRBO | 10 种子可行率 |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **TuRBO** | 经典贝叶斯信赖域 ($L_0 = 0.8$) | $195.73 \pm 12.32$ | $198.97$ | $164.24 \ / \ 207.55$ | Baseline | -- | **100% (10/10)** |
| **RL-Meta-TuRBO** | 纯净 PPO 离线强化元控制 | $206.81 \pm 14.21$ | $207.92$ | $176.64 \ / \ 234.45$ | $+11.09$ ($+5.7\%$) | $t=+2.077\ (p=0.068, d=+0.66)$ | **100% (10/10)** |
| **LLM-Meta-TuRBO** | 零泄漏停滞自适应大模型元控制 | **$227.40 \pm 13.41$** | **$225.10$** | **$200.76 \ / \ 247.11$** | **$+31.67$ ($+16.2\%$)** | **$t=+4.375\ (p=0.0018, d=+1.38)$** | **100% (10/10)** |
| **MALIBO (Paper-Exact)** | 原论文版无似然元学习 + 全局 5,120 采集 | $179.81 \pm 9.29$ | $180.00$ | $166.66 \ / \ 192.86$ | $-15.92$ ($-8.1\%$) | $t=-3.107\ (p=0.0126, d=-0.98)$ | **100% (10/10)** |

### 3.2 收敛效率与跨范式机理剖析
1. **零泄漏 `LLM-Meta-TuRBO` 以显著优势领跑全周期**：
   - 在完全去除提示词数值暗示与硬编码里程碑后，`Qwen/Qwen3.8-27B-FP8` 仅凭物理推理即在 10 种子中以 **$9/10$ 胜率**显著击败 `TuRBO`（$+31.67, p=0.0018, d=1.38$）与 `RL-Meta-TuRBO`（$+20.59, p=0.0134, d=0.97$），峰值达 **$247.11$**（`Seed 42`），平均单种子仅需 **$39.4\,\text{s}$**（均值 $5.1$ 次真实 LLM 推理）；
   - 到达 $L/D \ge 200$ 仅需 **120 步**（vs `RL-Meta-TuRBO` 261 步，**2.18× 加速**；`Vanilla-TuRBO` 300 步均值未达 200）。
2. **严格原论文版 `MALIBO` 呈现鲜明的“早期 >2× 效率领先 + 后期全局采样饱和”双阶段规律**：
   - **早期超 2× 迁移加速**：达到 $L/D \ge 100$ 仅需 **21 步**（vs `RL-Meta-TuRBO` 51 步 **2.43× 加速**，vs `TuRBO` 46 步 **2.19× 加速**）；达到 $L/D \ge 120$ 仅需 **31 步**（vs `RL-Meta-TuRBO` 80 步 **2.58× 加速**，vs `TuRBO` 69 步 **2.23× 加速**）；在 **NFE 16–147** 持续领先 `RL-Meta-TuRBO`、在 **NFE 16–166** 持续领先 `TuRBO`（第 100 步 $155.07 \pm 6.64$，标准差仅为 `TuRBO` 的 $29\%$）；
   - **后期精细剥削饱和**：受限于原论文 Appendix G 的全局 $[0,1]^{18}$ 5,120 点均匀采样（无局部信赖域收缩），150 步后命中极小高精邻域的概率骤降，最终收敛于 **$179.81 \pm 9.29$**（全场最低跨种子方差），与 3D 叶片（$D=63$）中的高维强约束流形采样瓶颈形成贯通的科学证据链。

## 4. 代码仓库结构与快速复现

```bash
RL-Airfoil/
├── src/
│   ├── evaluator.py          # 10 项航空工业级几何/气动强约束评估器 (NeuralFoil xxxlarge)
│   ├── airfoil_utils.py      # NACA0012 参数、18 维 Kulfan 搜索盒与闭合坐标生成
│   ├── ppo.py                # PPO Actor-Critic 双头网络、O(1) 回报缩放与 GAE 更新
│   ├── llm_agent.py          # 零泄漏 2D LLM 元控制智能体 (对称正交物理模式)
│   └── optimizers/           # 6 大纯净 RL-Meta 优化器 (零动作恒等) + 停滞自适应 LLM-Meta-TuRBO
├── train.py                  # 10 核 spawn 并行 PPO 元训练脚本 (220 回合, 单线程 BLAS 防争抢)
├── benchmark.py              # 6 优化器 10 种子 Vanilla vs RL-Meta 并行测试脚本
├── benchmark_llm_malibo.py   # 四大范式 10 种子统一基准评测脚本
├── plot_results.py           # RL-Meta 阶段全套出版级图表 (figures/rl_meta/)
├── plot_llm_malibo.py        # 四大范式出版级图表 (figures/llm_malibo/)
├── launch_sglang.sh          # 本地 SGLang Qwen3.8-27B-FP8 服务启动脚本
├── weights/                  # 6 个纯净 Meta-PPO 权重 (.pt)
├── results/                  # 10 种子全量 JSON/NPZ 实验数据
└── figures/                  # 300 DPI PNG 与 PDF 矢量图
```

### 复现命令
```bash
# 1. 训练 6 大纯净 Meta-PPO 策略 (220 轮覆盖 2 遍 110 工况网格)
python train.py --episodes 220 --num_workers 10 --device cpu

# 2. 运行 6 优化器 10 种子基准对比并绘图
python benchmark.py --num_workers 10 --device cpu
python plot_results.py

# 3. 启动本地 SGLang 服务，运行四大范式对比测试并绘图
bash launch_sglang.sh
python benchmark_llm_malibo.py
python plot_llm_malibo.py
```
